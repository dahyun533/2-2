# 2-2(mission6) 두 AI로 HTML 만들고 테스트하기

코디세이 AI 네이티브 입학연수과정 미션6 제출물.

- **미션:** 같은 기획서로 두 AI에게 HTML을 받아 같은 순서로 테스트하고, 고른 결과물을 고침.
- **한 것:** Claude(A)·ChatGPT(B) 비교. B는 굽는 중 경고 기능이 작동하지 않아 A 선택. 직접 써 보며 36번 수정함.
- **결과:** 처음 쓰는 사람 입장에서 멈칫한 곳(어려운 낱말, 다그치는 말투, 기록이 사라지는 버튼 등)을 고쳐 v2 완성.
- **완성본:** `html/단풍나무(v2_Claude).html`

## 파일 목록

- `html/단풍나무(v2_Claude).html`
- `md/기획서(v2).md`
- `md/제작검증기록(v2).md`

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 대화 캡처는 `AI이름_대화캡처번호.png`로 저장. 예: `claude_대화캡처1.png`, `chatgpt_대화캡처1.png`.
- 괄호 안은 내가 구분하려고 붙인 버전. 예: `기획서(v2).md` = 두 번째 기획서.
